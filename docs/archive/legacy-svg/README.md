**not referenced by the current README** and are retained here for reference only.

- none of them was linked from the rendered profile;

  anywhere in the repository and cannot be verified;

  (for example Angular, Vue, Go, Ruby, blockchain, and DeFi) that are not used by the
  projects featured in the current profile.

`architecture_overview.svg` and `security_focus.svg` are generic conceptual diagrams.
They are also not part of the current profile.

architecture. The rendered profile is [`README.md`](../../../README.md); the latest
verification evidence is in [`docs/evidence/verification-report.md`](../../evidence/verification-report.md).
