🔌 MCP Servers

Six local-first servers, published on npm and listed in the official MCP registry. Each repository documents its tools and configuration. Node.js 20.19+ is required (trace-inspector requires 22.13+, eval-runner 22.5+).

Run any package with npx -y <package>@latest (replace <package> with the server name).

Server What it does
mcp-agent-trace-inspector · npm Local-first tracing, cost estimates, diffs, and audit logs for MCP agent workflows.
mcp-cost-tracker-router · npm Offline token/cost tracking, budget alerts, and model-routing suggestions.
mcp-data-pipeline-connector · npm Cross-source SQL over CSV/JSON, PostgreSQL, and REST via embedded DuckDB.
mcp-eval-runner · npm YAML-driven regression tests for MCP servers and agent workflows.
mcp-legal-doc-analyzer · npm Local clause extraction, risk flagging, compliance checks, and version diffs.
mcp-server-health-monitor · npm MCP-native health checks, schema-drift detection, and local history.

🧪 Repository Verification

Verification & maintenance commands

This repository is the source for my GitHub profile README. There is no application server or build step: GitHub renders README.md directly.

Prerequisites: Python 3.12+; Playwright 1.55+ for screenshots; Node.js 20.19+ only for the optional MCP package audit.

python3 -m pip install -r requirements-dev.txt
python3 -m playwright install chromium

make check          # unit tests + README structure, assets, secrets, and links
make preview        # render README through GitHub's Markdown API
make screenshots    # capture desktop/mobile evidence with Playwright

The link and registry checks require network access. No secrets or environment variables are required. GITHUB_TOKEN is optional and only raises GitHub API rate limits for make preview.

Validation report, screenshots, and residual risks: docs/evidence/verification-report.md.

Secure by design. Verified by evidence.
